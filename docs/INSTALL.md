# Установка и использование

## Установка APK

1. Скачайте `neuro-stenographer-<версия>.apk` из GitHub Releases (ссылка в `artifacts/README.md`).
2. Разрешите установку из неизвестных источников и установите APK.
3. Телефон: Android 8.0+ (API 26), процессор **arm64-v8a**, свободно ≥ 2 ГБ (модели копируются во внутреннюю память).

Интернет приложению не нужен: release-сборка не содержит разрешения INTERNET и работает в авиарежиме.

## Первый запуск

Экран «Подготовка моделей» копирует модели из APK во внутреннюю память (один раз, прогресс на экране).
Если не хватает места — приложение скажет об этом; освободите место и нажмите «Повторить».

## Обработка записи

1. **Записи → Импорт файла** — системный выбор файла (mp3, m4a, ogg, wav, flac, amr…), или
   **Записать** — запись с микрофона в WAV 16 кГц моно.
2. На экране **Обработка** выберите число спикеров (Авто или 2–6) и переключатели LLM, нажмите
   **Начать обработку**. Этапы и общее время видны на экране и в уведомлении; можно свернуть приложение.
3. **Расшифровка**: реплики с цветом спикера и таймкодом; тап — перемотка плеера, долгое нажатие —
   правка текста или смена спикера. Вкладка **Итоги** — краткое содержание от LLM;
   оно и имена спикеров (если люди представились) появляются через пару минут после расшифровки —
   её можно читать и править сразу.
4. Меню **⋮**: переименовать спикеров, **Экспорт JSON / TXT / SRT** (системный диалог сохранения), «Поделиться».

JSON экспортируется строго в формате организаторов (сырой текст ASR с вашими правками; правка LLM
в строгий экспорт не попадает).

## Сборка из исходников

Требования: Android Studio (Standard setup: SDK, JBR), Node.js LTS, JDK 21 для Gradle из терминала
(Gradle 8.14 не запускается на JDK 25 — в Android Studio выберите *Settings → Build Tools → Gradle → Gradle JDK* = 21).

```bash
scripts/fetch_sherpa.sh          # .so и Kotlin API sherpa-onnx
scripts/download_models.sh --with-llm   # модели в assets/models (+ LLM Qwen3-1.7B для итогов)
cd src/web && npm ci && npm run build && npx cap sync android
cd ../android && ./gradlew assembleDebug        # или assembleRelease
```

Подпись release: создайте `src/android/keystore.properties` (вне git):

```properties
storeFile=../release.jks
storePassword=...
keyAlias=steno
keyPassword=...
```

Без него release подписывается debug-ключом (Gradle выводит предупреждение). Полная сборка релиза —
`scripts/build_release.sh` (проверяет отсутствие INTERNET и мока, кладёт APK в `artifacts/apk/`).
